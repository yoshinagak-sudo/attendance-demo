はじめに

本システムは2つのWebアプリで構成されています。同じデータを共有し、用途と利用者に応じて使い分けます。

用途URL主な利用者

このマニュアルの読み方

manager 経営層・部長・課長など承認権限を持つ人
member 現場社員・パート・バイト
developer システム保守担当（社内SE / 外部開発者）

1アカウント作成・ログイン

本アプリには 2 通りのログイン方法があります。どちらか好きな方を選んでください。 一度作成したアカウントは、後から両方の方法で入れるように紐付けることもできます。

方法初回2回目以降
メールアドレス + パスワード「新規登録」フォームに名前・メアド・パスワードを入力同じメアドとパスワードで入る
LINE で入る「LINEでログイン」→ 認可 → 名前を入力して登録完了「LINEでログイン」をタップするだけ
ログイン画面（モバイル）

1-1. 既にアカウントがある場合（ログイン）

  1. スマホのブラウザで https://attendance-demo-dun.vercel.app を開く
  2. メールアドレスとパスワードを入力して「ログイン」をタップ
    または「LINEでログイン / 新規登録」をタップ
  3. 役割に応じた画面に自動遷移（manager / developer は管理画面、member はホーム）
パスワードを忘れた場合は管理者に依頼してください。管理者がユーザー管理画面から新しいパスワードを発行できます（第11章参照）。

1アカウント作成・ログイン（つづき）

1-2. メールアドレスで新規登録する

  1. ログイン画面の下部にある「初めての方は 新規登録」をタップ
  2. 新規登録画面で 4 項目を入力
    • お名前（会社で表示される名前。例: 山田 太郎）
    • メールアドレス（次回ログインで使います）
    • パスワード（8 文字以上 100 文字以内）
    • パスワード（確認用）— 上と同じものを入力
  3. 「アカウントを作成してログイン」をタップ → そのままホーム画面に入ります
メアド新規登録画面（モバイル）
新規登録した直後のロールは member です。 管理者権限が必要な人は、登録後に管理者から manager に切り替えてもらってください（第11章参照）。

1-3. LINE で新規登録する（初回ログイン）

  1. ログイン画面の「LINEでログイン / 新規登録」をタップ
  2. LINE の認可画面で「許可する」をタップ
  3. 初回のみ「名前確定画面」が表示される。LINE の表示名が初期値として入っているので、必要なら会社で使う名前に書き換えて「登録を完了する」をタップ
  4. そのままホーム画面に入ります
LINE 初回登録時の名前入力画面
2 回目以降は LINE ボタンをタップするだけで一瞬で入れます。名前入力画面は出ません。

2打刻のしかた

出勤・退勤は巨大ボタンを1タップするだけ。 今が出勤中なら「退勤」、退勤済または未打刻なら「出勤」が自動表示されます。

  1. 画面中央の大きなボタン（緑=出勤 / オレンジ=退勤）をタップ
  2. 瞬時に記録され、画面下部の「本日の打刻履歴」に追加されます
  3. 状態バッジ（出勤中／退勤済／未打刻）が更新されます

残業申請への動線

打刻ボタンの下に「残業申請へ」リンクカードがあります。 その日の退勤打刻後に残業申請を出す場合はこちらから。

セッションは12時間有効。30分操作がないと自動的にログアウトします。

3残業申請を出す（社員）

member 現場社員や蛸と衣メンバーが、残業の事前申請・事後申請を提出する画面です。

3-1. 申請履歴を見る

  1. ヘッダー「[名前]▾」メニュー → 残業申請
  2. または打刻画面下部の「残業申請へ」リンクから
自分の申請履歴一覧

状態バッジの見方

  • 申請中：承認待ち
  • 承認済：完了
  • 差戻：修正が必要、再申請可能
  • 却下：認められなかった

3-2. 新規申請を出す

  1. 「+ 新規申請を作成」をタップ
  2. 申請種別を選ぶ（事前申請 / 事後申請）
  3. 申請日と残業開始/終了時刻を入力（退勤打刻があれば自動セット）
  4. 現場名（過去使用順でサジェスト）と作業内容（200文字以内）を入力
  5. 「確認画面へ →」で内容確認 → 「申請を送信する」で完了
事後申請は当日中のみ受け付けます。翌日以降の遡及はできません（事前申請推奨）。

差戻された申請の再申請

差戻になった申請を開くと、「再申請する」ボタンが表示されます。前回値がプリフィルされた状態で フォームが開くので、コメントに沿って修正して送信します。

新規申請フォーム

4勤怠ダッシュボード（管理者）

manager 出勤中の社員・労働時間・長時間勤務の警告を1画面で把握します。 manager でログインすると最初に表示される画面です。

  1. ログイン直後の画面、もしくはヘッダーメニュー → 「管理画面」
  2. 上部の AI 今日のサマリー で全体状況を1行で確認
  3. 未承認バナー から残業承認キューに直接ジャンプ可能
  4. KPI 4枚（出勤中 / 退勤済 / 未出勤 / 合計労働時間）と タイムライン（ガントチャート） で詳細を確認
勤怠ダッシュボード（PC表示）
タイムラインは 緑=出勤中 / グレー=退勤済 / 赤=10時間超 で色分けされます。 現在時刻の縦線（NOW）も表示されるので「今どうなっているか」が一目で分かります。

5残業申請の承認（管理者）

manager 申請中の残業を「承認 / 差戻 / 却下」で処理します。 差戻と却下はコメントが必須です。

  1. ヘッダー → 「管理画面」→ 「承認キュー」、または未承認バナーから直接
  2. 申請カードの「承認」をタップで即時承認
  3. 「差戻」または「却下」をタップ → コメント入力欄が展開 → 確定
  4. 処理後はフィルタ「すべて」で過去の承認履歴も確認可能
残業承認キュー（PC表示）

差戻・却下の違い

操作意味申請者の次のアクション
承認申請を確定。月次集計に反映不要
差戻修正してもう一度出してほしいコメントを見て再申請
却下申請を認めない原則終了

6月次レポート・CSV出力

manager 実労働時間と承認済残業を月次で突き合わせ、CSVでダウンロードできます。 給与計算用・労務監査用の出力が想定です。

  1. 「管理画面」→ ヘッダーの「月次レポート」
  2. 月切替ナビ（◀／▶）または月選択フォームで対象月を選ぶ
  3. 合計バッジ4枚で月次サマリーを把握（承認済 / 申請中 / 却下 / 差分注意者）
  4. 「CSV（承認済）」または「全件CSV」ボタンでダウンロード
月次レポート（PC表示）

CSV出力の列

申請ID / 業務日 / 申請者 / 申請種別 / 状態 / 開始時刻 / 終了時刻 / 残業時間（分）/ 残業時間（h:mm）/ 現場名 / 作業内容 / 承認者 / 承認日時 / 差戻コメント

UTF-8 BOM付き・CRLF改行で出力されます。Excel で開くと文字化けせずに表示されます。

7ユーザー管理（管理者）

7-1. 設定

manager 所定終業時刻と現場名マスタを管理します。

  • 所定終業時刻：残業申請フォームの開始時刻デフォルト値（初期 17:30）
  • 現場名マスタ：申請時のサジェストに出る現場一覧。追加・無効化が可能
設定画面

7-2. ユーザー管理

manager 各社員のパスワード再発行・ロール変更・有効/無効切替を行います。

  1. ヘッダーメニュー → 「ユーザー管理」
  2. パスワードを忘れた社員の行で「PW再発行」をタップ
  3. 新しいパスワードが画面に1回だけ表示されるので、本人に渡す
  4. 退職者は「無効化」で非アクティブ化（過去の履歴は保持）
  5. ロール列のセレクトで 一般 / 管理者 / 開発者 を切替
最後の管理者(manager/developer)は無効化・降格できません（システムがロックされるのを防ぐため）。 自分自身のロールは変更不可。
ユーザー管理画面

8アカウント設定（連携・ログイン方法）

画面右上のユーザーメニュー →「設定」から、自分のアカウント情報と ログイン方法の連携状況を確認・変更できます。

確認できる項目

  • 名前・ロール（manager / member / developer）
  • メールアドレス・最終ログイン日時
  • メアド/LINE それぞれの連携状況

できる操作

  • LINE と連携する: メアドで入っている人が「LINEと連携する」ボタンを押すと、自分のアカウントに LINE userId が紐付き、以降はどちらの方法でも同じアカウントに入れます。
  • LINE 連携を解除する: メアド+パスワードが設定済みのアカウントは、LINE 連携を外せます（メアドだけのアカウントに戻ります）。
メアド未設定の LINE 専用アカウントは、解除するとログイン手段がなくなるため解除できません。先にメアド+パスワードを登録してから解除してください。
アカウント設定画面（モバイル）

9車両管理

社用車の割当・走行記録・給油記録を一元管理。スマホで現場社員が登録し、 管理者は当日の利用状況・月次走行距離・燃費・給油代を把握できます。

使い方の流れ（社員）

  1. 「車両管理」を開き、空いている車両の「この車両を使う」をタップ
  2. 現場に向かう前に「出発を登録する」
  3. 出発時メーター・目的（据付/保守点検 等）・現場名を入力
  4. 帰社後に「帰着を登録する」で帰着時メーターを入力
  5. 給油時は「給油を登録する」から量・金額・給油所を記録
1日1台が基本。別の車両に変更したい場合は、新しい車両で「使う」を押すと 前の割当が自動で解除されます。

11入力負担を減らす3つの工夫

現場社員は両手で作業しています。少しでも「アプリの操作」に取られる時間を減らすため、 車両管理・日報まわりに3つのショートカットを用意しました。

① 車両QRコードでワンタッチ割当

各車両のキーケースやダッシュボードに専用QRコードを貼り付け、 スマホでスキャンするだけで自動的に「この車両を使う」画面に遷移します。 ログイン中ならその場で割当完了。

  1. 管理画面 → 「車両マスタ」 → 各行の「QR」ボタンで印刷用ページを開く
  2. A6サイズで印刷、車両にラミネートして貼付
  3. 社員はカメラアプリでQRをスキャン → そのまま割当画面へ
車両ごとのQRコード印刷ページ

② メーター撮影で自動入力（AI画像認識）

出発・帰着時のメーター入力欄に「📷 メーターを撮影」ボタンを配置。 スマホのカメラでメーターを撮影すると、Google Gemini Vision AIが 積算走行距離(ODO)を自動で読み取って入力欄に反映します。

  • 確信度（高/中/低）を表示。低い場合は手入力を案内
  • 手袋を外さずに撮影だけで完結
  • 誤入力（5桁目を打ち忘れ等）の防止に有効
注：暗所・反射・極端な斜め撮影では読み取れない場合があります。 その場合は従来通り手入力できます。
出発登録画面のOCR撮影ボタン

③ 車両走行ログから日報を自動下書き

日報の作成画面を開くと、当日の車両走行ログ（出発・帰着）から作業アイテムが自動で雛形化されます。 現場名・目的・時刻が既に入った状態でフォームが開くので、社員は「作業内容の一言」を足すだけ。 1日3〜4現場を回る業態でも、日報作成は1〜2分で完了します。

  • 走行ログがない日は、打刻からの時刻のみが自動入力されます
  • 自動入力後に編集・追加・削除は自由
  • 「車両走行から取り込みました」バナーで成功表示

16よくある質問

Q. 管理ダッシュボードのパスワードを忘れました
システム管理者（開発者）に依頼してください。Vercel 環境変数 NINAU_OWNER_PASSWORD_HASH を新パスワードのハッシュで差し替えることで即時切替できます。
Q. ダッシュボードから残業申請を承認できますか？
できません（閲覧専用）。承認は社員向け勤怠アプリ（attendance-demo-dun.vercel.app）に管理者(manager)アカウントでログインして行ってください。
Q. スマホ以外でも使えますか？
PC・タブレット・スマホすべてで動作します。画面サイズに応じて自動でレイアウトが切り替わります。
Q. パスワードを忘れました
管理者に依頼してください。ユーザー管理画面の「PW再発行」で新しいパスワードを発行し、画面に1回だけ表示されるので本人に渡します。LINE 連携済みの場合は LINE でログインして「設定」画面からメアド+パスワードを再設定する手もあります。
Q. メアドと LINE どちらでも入れるようにするには？
どちらか一方でログインした後、画面右上「設定」→「LINE と連携する」で自分のアカウントに紐付けます。以降はどちらの方法でも同じアカウントに入れます。
Q. 打刻のミスは管理者が修正できますか？
現状は打刻の編集機能は未実装です（要望が多ければ追加検討）。残業申請は社員自身が差戻→再申請できます。
Q. データは安全ですか？
パスワードは PBKDF2-SHA256 でハッシュ化、セッションは HMAC 署名付き HttpOnly Cookie。データベース（Turso）は東京リージョンで保管され、TLS で暗号化通信されます。
Q. 給与計算ソフトと連携できますか？
月次レポートから CSV をダウンロードできます（UTF-8 BOM、Excel互換）。現状は汎用フォーマットですが、freee / マネーフォワード等の特定フォーマットへの拡張は対応可能です。
Q. 何人まで使えますか？
技術的には数百人規模まで対応可能。
