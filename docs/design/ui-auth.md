# 個別アカウント認証 UI 設計メモ

ログイン制を導入したあとの画面構成。Tailwind不採用、`app/globals.css` のトークン (`--primary`, `--warn`, `--danger` 等) を組み合わせて plain CSS で記述。

## 共通

- 共通ヘッダ `AppHeader`（左: BFマーク+「勤怠アプリ」、右: ユーザー名ボタン + dropdown）
- 全ページのコンテナ直下に `<AppHeader user={session} />` を render
- 既存のページ内ヘッダ（`.header`：見出し + 戻るリンク）はそのまま下に残す
- ログアウト操作は dropdown 内に集約

```
  │                          │
  │ (エラーがあればここ赤帯)  │

  │ ログイン情報を忘れた場合は │
  │ 管理者にお問い合わせください │
  └──────────────────────────┘
```

- 既存の `.ot-auth-shell` / `.ot-auth-card` を流用しつつ、login専用クラス `login-*` を追加
- input 最小タップ領域 56x56、フォントは 16px 以上で iOS auto-zoom 抑止
- パスワード可視化トグル付き（タブレットでの誤入力対策）
- pending時はボタン disabled + spinner

## /（打刻画面）

```
[AppHeader]
─────────
[戻るリンク等は無し（打刻はトップ）]

  [大時計 80px]   2026/05/12 (月) 09:23

  ┌──────────────────────────────┐
  │ 現在のステータス               │
  │ ●  出勤中  / 09:01 から         │
  └──────────────────────────────┘

  ┌══════════════════════════════┐
  ║                              ║
  ║      [ 退勤 ]  (warn色)       ║
  ║   タップで退勤を記録します      ║
  ║                              ║
  └══════════════════════════════┘
                ↑ min-height 120px、画面の主役

  ─ 本日の自分の打刻履歴 ─────────
   09:01  出勤
   08:50  出勤（取り消し済等の表示は無し、降順）

  ─────────────────────────────
  ┌──────────────────────────┐
  │ [ 次の人に渡す（ログアウト）] │  ← danger系
  └──────────────────────────┘
```

- 巨大CTAは状態によって2色:
  - 未打刻 or 退勤済 → `打刻-btn-in`（primary、ラベル「出勤」）
  - 出勤中 → `打刻-btn-out`（warn、ラベル「退勤」）
- 「次の人に渡す」は共有タブレット運用の名残り。誤タップ防止のため画面最下部
- 既存の punch-btn-* グリッドCSSは1人用のため不要 → 削除

## AppHeader

```
[BF 勤怠アプリ]                                  [本郷 拓也 ▾]
                                                ├─ 打刻画面
                                                ├─ 残業申請
                                                ├─ 管理画面 (manager)
                                                ├─ ユーザー管理 (manager)
                                                └─ ログアウト
```

- `<details><summary>` で実装。CSSのみで開閉、JS極小。
- ロール表示はバッジ（manager=primary-soft、member=なし）
- 名前長い人対策で max-width 12em + 省略

## /overtime

- actor選択UI（14名グリッド）を削除
- session 1人の履歴のみ表示
- 「+ 新規申請を作成」ボタンはそのまま、リンク先は `/overtime/new`（actorクエリ不要）

- 最後のmanager保護: 自分自身を無効化しようとした場合

- ロール列はバッジで表示（読み取り専用）
- Server Action は `useActionState` で受け、ok時にモーダル

## CSSのprefix

- `login-*`: ログイン専用
- `header-app-*`: 共通ヘッダ
- `user-menu-*`: dropdown
- `admin-users-*`: ユーザー管理テーブル
- `password-reveal-*`: パスワード再発行モーダル
- 既存 `punch-*` の一部（grid 関連）は削除。`punch-status-*`, `punch-cta-*`, `punch-handoff-*` を新規追加
